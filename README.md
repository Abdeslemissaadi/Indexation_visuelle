# 🖼️ Tiny ImageNet-200 Image Classification Project

Ce projet vise à explorer, charger et préparer le jeu de données **Tiny ImageNet-200** dans Google Colab / Jupyter Notebook pour des tâches d'apprentissage profond (Deep Learning) et de vision par ordinateur (Computer Vision).

---

## 📌 Présentation du jeu de données

Le dataset **Tiny ImageNet-200** est un sous-ensemble du célèbre jeu de données ImageNet. Il contient :
* **200 classes** d'images distinctes.
* **500 images d'entraînement** par classe (100 000 images au total).
* **10 000 images de validation** (50 images par classe).
* **10 000 images de test**.
* Des images de taille **64x64 pixels** au format JPEG.
